# Генератор сайта: Bash + POSIX awk

## На ноде

- `site_generator.sh` — аргументы CLI, seed, атомарная запись результата.
- `site-generator/design.awk` — все данные, CSS, варианты и функции рендера.
- `site-generator/runtime.awk` — коллекции, UTF-8, форматирование и случайный выбор.
- `site-generator/check.awk` — проверка структуры HTML до замены файла.
- `site-generator/main.awk` — генерация и пакетный аудит разнообразия.

Нужны Bash, awk и coreutils. Сеть для генерации не используется. Шрифты по-прежнему
локальные. Механизм сайта не меняет Caddy, сертификаты, firewall или Config Profile.
CLI не интерпретирует seed как shell/awk-код; произвольная строка хешируется SHA-256.

Это зависимости генератора, не всех системных пакетов установщика.
`unattended-upgrades` сохранён для автообновлений безопасности; в Debian
[12](https://packages.debian.org/bookworm/unattended-upgrades) и
[13](https://packages.debian.org/trixie/unattended-upgrades) он зависит от Python.
Наш runtime Python не вызывает, но полностью исключать его из ОС без отдельного
решения по автообновлениям нельзя.

Случайный выбор использует два целочисленных потока L'Ecuyer. Это не криптографический
генератор и не используется для ключей/паролей. Начальное состояние выводится из seed,
а при отсутствии `--seed` seed берётся из `/dev/urandom`. Идентификатор design signature
служит только аудиту разнообразия, не безопасности.

## Сохранение логики при переносе

Генератор содержит все исходные семейства и взаимозависимые варианты, а не упрощённый
набор шаблонов. Данные, CSS и рендер теперь поддерживаются непосредственно в awk.
Старый исходник, промежуточный конвертер и тесты на другом языке удалены из текущего
дерева репозитория. При необходимости их можно восстановить из истории Git.

Генератор случайных чисел изменён; побайтовое совпадение старого seed не обещается.
Сохранены алгоритмы выбора, веса, семейства, порядок операций, CSS и локальные SVG.
Единственные намеренные изменения содержимого: удалены видимые служебные параметры
из подвалов и статистика генератора из data-first hero. Вместо них обычный текст
о направлении деятельности и организации, без дополнительного случайного выбора.

## Регрессии

- `tests/test-site-generator.sh` проверяет SHA-256 полного HTML для 100 фиксированных
  seed. Эталон взят из уже проверенного генератора `70c67fd`, сравнивавшегося при
  переносе с прежней реализацией на 500 seed. Нормализуется только незначимое
  форматирование десятичных чисел между реализациями awk.
- Нативный аудит 100 страниц проверяет уникальность, порядок секций, покрытие семейств
  и корректность структуры HTML. Каждый из шести вариантов подвала должен встретиться.
- Debian 12/13 запускают unit/integration-тесты и генератор с заглушками Python,
  которые завершаются ошибкой при любом вызове.
- `tests/test-ip-parser.sh` проверяет 2246 фиксированных результатов для 574 адресов
  и сетей: нормализацию, версию, принадлежность подсетям и нулевые префиксы. Данные
  получены из прежнего независимо проверенного корпуса; дополнительно проверяются
  некорректные строки и разделение семейств адресов.
- `tests/test-firewall-network.sh` проверяет пакеты в изолированных IPv4/IPv6-сетях,
  включая публичные порты, RST, UDP DROP и административные allowlist. В CI для него
  нужны socat и netcat-openbsd, на ноде эти тестовые зависимости не устанавливаются.
- CI не содержит вызовов прежнего интерпретатора; проверка репозитория запрещает
  повторное появление его исходников и байткода.

Генерация, аудит и все текущие тесты работают на Bash/awk и штатных CLI-утилитах:

```bash
bash tools/site_generator.sh --seed example --output /tmp/example.html --print-dna
bash tools/site_generator.sh --audit 100 --seed regression
bash tests/test-site-generator.sh
bash tests/test-ip-parser.sh
```

После обновления runtime существующий сайт сохраняется. `rw-node regenerate-site`
явно создаёт новый сайт. Переустанавливать систему или удалять Python вручную не нужно.
