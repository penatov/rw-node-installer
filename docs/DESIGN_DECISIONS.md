# Что сознательно включено и исключено

## nftables вместо iptables/UFW

Используется одна именованная `inet`-таблица для IPv4 и IPv6. Проект никогда не делает
глобальный `flush ruleset`, поэтому правила Docker и Remnawave Node Plugins могут жить рядом.
UFW и firewalld не используются. Если один из сторонних firewall уже активен или включён,
установщик останавливается и просит разобрать конфликт вручную.

## TrafficGuard

[traffic-guard](https://github.com/dotX12/traffic-guard) не включён по принятому решению.
Список адресов сканеров и эвристическое активное блокирование не дают гарантии против DPI,
зато создают дополнительный privileged-компонент, состояние и риск ложных блокировок.
Здесь административная поверхность закрыта allowlist, а публичные 443 намеренно отвечают
только реальными протоколами и Caddy-маскировкой.

## node-accelerator и производительность

Из идей [node-accelerator](https://github.com/jestivald/node-accelerator) оставлены только
настройки с понятной связью с этой нагрузкой: BBR+fq при поддержке ядром, backlog, границы
socket autotuning, conntrack/file limits и осторожный RPS для малоканальных виртуальных NIC.
Значения выбираются по CPU/RAM. Не применяются вслепую огромные буферы, отключение offload,
изменение всех NIC или параметры, которых нет в текущем ядре.

## Caddy, сайт и шрифты

Caddy выбран для ACME HTTP-01 и локального TLS target на 8443. Admin API отключён.
Сайт уникален для ноды и использует локальные WOFF2. Google Fonts сам по себе не считается
«плохим», но внешний font-запрос добавлял бы ненужную зависимость, DNS/HTTP-метаданные и
одинаковый сторонний индикатор для всех нод.

## fail2ban

fail2ban не устанавливается: SSH до аутентификации достижим только с IP панели и
администраторов. Для недоверенного Интернета нечего анализировать в sshd-журнале; второй
банящий механизм лишь усложнил бы восстановление. За перебор с уже доверенного IP отвечает
политика SSH и безопасность самой панели/административной сети.

## Предел маскировки

Silent drop полезен для закрытых портов, но неприменим к публичному 443: сервер обязан
ответить легитимному клиенту. REALITY fallback на настоящий TLS-сайт и Hysteria2 proxy
masquerade убирают очевидные пустые/ошибочные ответы, но не скрывают статистику трафика,
репутацию адреса, активные протокольные признаки или данные провайдера.
